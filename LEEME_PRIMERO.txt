  🚀 DEPLOYMENT EN 3 PASOS (5 MINUTOS TOTAL)
═══════════════════════════════════════════════════════════════════

PASO 1: Subir a GitHub (2 min)
  ├─ Doble click en: PREPARAR_GITHUB.bat
  ├─ Sigue las instrucciones en pantalla
  └─ Tu código estará en GitHub

PASO 2: Deploy en Render.com (3 min)
  ├─ Ve a: https://render.com
  ├─ Sign up with GitHub
  ├─ New > Web Service
  ├─ Conecta tu repositorio
  ├─ Build: pip install -r requirements.txt
  ├─ Start: gunicorn app.main:app
  └─ Create (espera 3-5 min)

PASO 3: Keep-Alive (30 seg)
  ├─ Ve a: https://uptimerobot.com
  ├─ Add Monitor > HTTP(s)
  ├─ URL: https://tu-app.onrender.com/ping
  └─ Interval: 5 minutes
