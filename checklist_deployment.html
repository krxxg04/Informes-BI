🚀 Checklist de Deployment

Marca cada paso cuando lo completes

📦 Paso 1: Preparar GitHub

  • Git instalado en mi PC
  • Cuenta de GitHub creada
  • Ejecuté: git init
  • Ejecuté: git add .
  • Ejecuté: git commit -m "Initial commit"
  • Creé repositorio en GitHub
  • Subí el código con git push

☁️ Paso 2: Deploy en Render

  • Cuenta de Render creada (render.com)
  • Conecté Render con GitHub
  • Creé nuevo Web Service
  • Configuré Build Command: pip install -r requirements.txt
  • Configuré Start Command: gunicorn app.main:app
  • Seleccioné plan Free
  • Deploy completado exitosamente

⏰ Paso 3: Keep-Alive con UptimeRobot

  • Cuenta de UptimeRobot creada (uptimerobot.com)
  • Creé nuevo monitor HTTP(s)
  • Configuré URL: mi-app.onrender.com/ping
  • Interval configurado a 5 minutos
  • Monitor activo y funcionando

✅ Paso 4: Verificación Final

  • La URL abre correctamente en el navegador
  • Puedo seleccionar un tipo de informe
  • Puedo llenar un formulario
  • Se genera y descarga el documento Word
  • Probé desde mi celular/tablet
  • Guardé la URL en favoritos
  • Le envié el link a mi mamá
